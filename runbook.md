# OpenGames — запуск локальной Beta

## Что это

OpenGames — локальная web-платформа интерактивных игр с AI-сценаристом. В репозитории есть каталог сценариев, авторизация, профили провайдеров, сохранение истории, карта исследования и сюжетный путь.

## Требования

- Node.js 22 или новее
- свободный порт `3000`

Проверка версии:

```bash
node --version
```

## Запуск

```bash
cd OpenGames
npm run dev
```

Откройте в браузере: <http://localhost:3000/>

Остановка: `Ctrl+C`.

## Первый запуск

1. Примите уведомление о local storage.
2. Откройте «Профиль» и зарегистрируйте демонстрационный аккаунт.
3. В разделе «AI-сценарист» добавьте собственный ключ провайдера, если нужно протестировать удалённую LLM.
4. Без ключа можно ознакомиться с интерфейсом и локальным deterministic fallback, если он разрешён текущей конфигурацией.
5. Вернитесь в каталог, откройте карточку сценария и выберите действие.

История хода сохраняется автоматически в локальном хранилище проекта. Ключи провайдеров не входят в архив и не должны добавляться в Git.

## Переменные окружения

Скопируйте пример только при необходимости:

```bash
cp .env.example .env
```

Заполните переменные актуальными ключами локально. Файл `.env` запрещён к публикации. Для ознакомления достаточно запуска без него.

## Основные файлы

- `src/server.ts` — HTTP-сервер и API.
- `src/core/` — runtime, движок состояния, AI Gateway, аккаунты и сохранения.
- `src/games/` — конфигурационные пакеты сценариев.
- `web/` — клиентский интерфейс.

## Проверка после запуска

```bash
curl http://localhost:3000/api/health
```

Ожидается JSON с `ok: true` и количеством доступных игр. Каталог должен открываться по адресу `http://localhost:3000/#/games`.

## Безопасность демонстрационной копии

В архиве отсутствуют `data/accounts.json`, `data/saves/*.json`, `.env` и Git-метаданные. При первом запуске сервер создаст пустые локальные каталоги данных автоматически.
