# OpenGames · Билд 0.0.7

## Изменения

- В каталог добавлены восемь самостоятельных сценариев повышенной сложности: дипломатический кризис, медицинский триаж, аварийное управление воздушным движением, паводковый штаб, кризис ликвидности, кинопроизводство, оркестровая премьера и океанская регата.
- Для каждого сценария подготовлен отдельный фон в `web/assets`; пакеты подключены к API каталога и запуску сессий.
- Правила проекта требуют проверять отсутствие тематического и игрового пересечения с каталогом и создавать изображение для каждого нового сценария.
- Версия портала обновлена до `BETA 0.0.7`.
